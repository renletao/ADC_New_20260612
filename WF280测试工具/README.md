# WF280 测试工具

**双击 `WF280测试工具.exe` 就能用**，不用装 Python、不用敲命令、不用命令行。

原「多功能小板测试」是编译好的 exe、没有源码，加不进 WF280 的新命令，
所以单独做了这个工具，专测 WF280 的全部功能，跟原工具并存、互不干扰。

## 第一次运行

1. 把 `WF280测试工具.exe` 拷到测试电脑任意位置（单独一个文件就行，不依赖其他文件）
2. 双击打开
3. 等 2~3 秒（单文件 exe 要先自解压，之后启动会快一些）

> 如果 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。
> 这是未签名程序的常规提示，不是病毒。

## 使用流程

1. **选串口** → 插上板子后点「刷新」，选中对应的 COM 口（CH340 那类）
2. **点「连接」**（波特率和从机地址默认 115200 / 1，一般不用改）
3. 连上后顶部会显示 **「设备：固件 v1.0 · COM20 · 115200 8N1 · 从机 1」**
   —— 先看版本号对不对、是不是要测的那块板子
4. 然后按需要点测试：
   - **① 整机测试**：一键跑完整流程，结果逐项列出，右侧直接显示 PASS / NG
   - **② 轨压回读**：显示实测轨压，可勾「连续监测」每 0.5 秒刷新
   - **③ 单项命令**：OTP 校验、输出测试 3.3 V / 2.0 V、读系数、读 M1

底部是运行日志，带时间戳，判定 NG 的项标红。

## 覆盖的命令

| 功能 | 命令 | 方式 | 返回 |
| --- | --- | --- | --- |
| 固件版本 | `{1, 0x104}` | 同步 | 主版本 / 次版本 |
| 整机测试 | `cmd[0] = 14` | 异步，走 `IsTaskDone` 队列 | 32 个寄存器：状态、轨压、电流、系数 |
| 轨压回读 | `{1, 0x211}` | 同步，随时可读 | 状态 + mV |
| OTP 校验 | `{11}` | 同步 | 1=通过 / 0xFF=失败 + 失败路号 |
| 输出测试 3.3 V | `{1, 0x208, 测量参数, 稳定时间}` | 同步 | 状态 + 6 个原始字节 |
| 输出测试 2.0 V | `{1, 0x210, 测量参数, 稳定时间}` | 同步 | 状态 + 6 个原始字节 |
| 读正常 bank 系数 | `{1, 0x209, 路数}` | 同步 | 状态 + N 路 16 位系数 |
| 读 M1 bank 系数 | `{1, 0x207, 路数}` | 同步 | 状态 + 待机/工作电流码 + N 路系数 |
| 设定 DAC 轨压（辅助） | `{1, 0x201, lo, hi}` | 同步 | 状态 |

命令码、结果偏移、判定阈值都对应固件 `Core/Src/wf280.c`、`Core/Inc/wf280.h`。
板子侧：USART2，**115200 8N1**，Modbus RTU 从机地址 **1**。

## 三个注意点

0. **先读版本再测**
   连上后第一件事是读 `{1, 0x104}`，正常返回 `v1.0`。
   如果读到 `0.0`，说明设备没应答或固件没烧进去，这时点测试只会拿到一堆 0。

1. **寄存器地址不是 0 基偏移**
   固件里 `eMBRegHoldingCB` / `eMBRegInputCB` 直接比较 `40001` / `30001`，
   所以 PDU 里必须写 40001 和 30001 本身。按标准 Modbus 习惯写 0 会返回异常码 2。

2. **轨压读到的是实测值，不是设定值**
   `0x211` 走 PB1/ADC1_IN9 分压回采，读到的是 DUT 真实轨压。
   「设了 3300 却读到 1200」说明轨没起来，不是命令没生效。

## 源码与重新打包

界面和协议是 Python 写的，已打包进 exe，**日常使用完全不需要 Python**。
只有要改功能时才需要动源码：

```
src/
  wf280_tool.py    入口（图形界面 / 命令行）
  gui.py           tkinter 界面
  wf280_proto.py   命令封装与结果解码
  mb_rtu.py        极简 Modbus RTU 主站（不依赖 pymodbus）
  selftest.py      离线自检
build.bat          一键重新打包
```

重新打包：装 Python 3.8+（官方版，自带 tkinter）和 `pip install pyserial pyinstaller`，
然后双击 `build.bat`，根目录会生成新的 exe。

离线自检（不需要板子，用假从机验证协议，14 项）：

```
python src/selftest.py
```

命令行用法（需要源码环境）：

```
python src/wf280_tool.py --port COM5 version
python src/wf280_tool.py --port COM5 full
python src/wf280_tool.py --port COM5 rail
```

退出码：`0` 通过、`1` NG、`2` 通讯错误，方便产线脚本判断。
